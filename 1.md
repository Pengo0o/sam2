# Feature Fusion Implementation Plan for SAM2

## Overview

Implement a temporal feature fusion mechanism **as a parallel refinement branch** that:
1. Fuses encoder layer 0 and layer 1 features
2. Extracts prototypes from frame t using 5 learnable query embeddings
3. Conditions frame t+1 features on frame t prototypes via cross-attention
4. Creates a parallel refinement branch that generates refined masks
5. Trains both original and refined masks with combined loss

**Important Design Principles**:
- **Dual-branch architecture**: Original SAM2 branch + Refinement branch running in parallel
- **Non-invasive to original flow**: Original mask prediction unchanged
- **Minimal decoder changes**: Only add new tokens and return upscaled_embedding
- **Combined supervision**: `total_loss = loss_original + loss_refine`
- **Backward compatible**: Can disable refinement branch via config flag

## Architecture Overview

### Dual-Branch Design

```
                    ┌─────────────────────────────────────┐
                    │   Original SAM2 Branch              │
                    │   (unchanged, for loss_original)    │
                    └─────────────────────────────────────┘
                                    ↓
                            Original Masks

                    ┌─────────────────────────────────────┐
                    │   Refinement Branch                 │
                    │   (new, for loss_refine)            │
                    └─────────────────────────────────────┘
                                    ↓
                            Refined Masks

Total Loss = loss_original + loss_refine
```

### Complete Pipeline Flow

```
Frame t:
  ┌──────────────────────────────────────────────────┐
  │ 1. Encoder Features                              │
  │    layer[0]: [B, C0, H, W]                       │
  │    layer[1]: [B, C1, H/2, W/2]                   │
  └──────────────────────────────────────────────────┘
                    ↓
  ┌──────────────────────────────────────────────────┐
  │ 2. FeatureFusion                                 │
  │    layer[0] → Conv1x1 → [B, hidden_dim, H, W]    │
  │    layer[1] → Upsample + Conv1x1 → [B, hidden_dim, H, W] │
  │    Add → fused_feat_t [B, hidden_dim, H, W]      │
  └──────────────────────────────────────────────────┘
                    ↓
  ┌──────────────────────────────────────────────────┐
  │ 3. PrototypeExtractor                            │
  │    5 queries attend to fused_feat_t              │
  │    Output: prototypes_t [B, 5, hidden_dim]       │
  │    → Store for frame t+1                         │
  └──────────────────────────────────────────────────┘

Frame t+1:
  ┌──────────────────────────────────────────────────┐
  │ 1-3. Same as Frame t                             │
  │    → fused_feat_t+1, prototypes_t+1              │
  └──────────────────────────────────────────────────┘
                    ↓
  ┌──────────────────────────────────────────────────┐
  │ 4. SAM Decoder (Modified)                        │
  │    Input:                                        │
  │      - backbone_features (memory-conditioned)    │
  │      - mask_tokens (4 original tokens)           │
  │      - refine_tokens (N new tokens)              │
  │    Process:                                      │
  │      - Concat all tokens → Transformer           │
  │      - Original pipeline:                        │
  │          mask_tokens_out → hypernetwork → masks  │
  │      - NEW: extract refine_tokens_out            │
  │    Output:                                       │
  │      - original_masks                            │
  │      - iou, obj_ptr, etc. (unchanged)            │
  │      - upscaled_embedding [B, C, H_up, W_up]     │
  │      - refine_tokens_out [B, N, transformer_dim] │
  └──────────────────────────────────────────────────┘
                    ↓
  ┌──────────────────────────────────────────────────┐
  │ 5. Refinement Branch (NEW, in SAM2Base)          │
  │                                                  │
  │  a) Prepare Combined Features:                   │
  │     - original_masks resize → [B, 1, H, W]       │
  │     - Concat [fused_feat_t+1, masks] → [B, hidden_dim+1, H, W] │
  │                                                  │
  │  b) Prototype Conditioning:                      │
  │     - Conv1x1 projection: [B, hidden_dim, H, W]  │
  │     - Cross-attn with prototypes_t               │
  │     - Output: cross_attn_result [B, hidden_dim, H, W] │
  │                                                  │
  │  c) Feature Enhancement:                         │
  │     - upscaled_embedding → Conv1x1 → [B, hidden_dim, H_up, W_up] │
  │     - cross_attn_result resize → [B, hidden_dim, H_up, W_up] │
  │     - Add → enhanced_feat [B, hidden_dim, H_up, W_up] │
  │                                                  │
  │  d) Token Modulation:                            │
  │     - refine_tokens_out → MLP → [B, N, transformer_dim] │
  │     - Mean/Pool → [B, transformer_dim]           │
  │     - Linear → [B, hidden_dim]                   │
  │     - Reshape → [B, hidden_dim, 1, 1]            │
  │                                                  │
  │  e) Generate Refined Masks:                      │
  │     - modulated_feat = enhanced_feat * (1 + token_weights) │
  │     - Conv1x1 → [B, 1, H_up, W_up] (refine mask) │
  │                                                  │
  └──────────────────────────────────────────────────┘
                    ↓
  ┌──────────────────────────────────────────────────┐
  │ 6. Loss Computation                              │
  │    loss_original = loss_fn(original_masks, gt)   │
  │    loss_refine = loss_fn(refine_masks, gt)       │
  │    total_loss = loss_original + loss_refine      │
  └──────────────────────────────────────────────────┘
```

```python
class FeatureFusion(nn.Module):
    """Fuses encoder layer 0 and layer 1 features via separate projections"""
    def __init__(self, input_dim_layer0, input_dim_layer1, output_dim):
        super().__init__()
        # Separate 1x1 convs for each layer
        self.conv_proj_layer0 = nn.Conv2d(input_dim_layer0, output_dim, kernel_size=1, bias=False)
        self.conv_proj_layer1 = nn.Conv2d(input_dim_layer1, output_dim, kernel_size=1, bias=False)
        self.norm = nn.LayerNorm(output_dim)
        self.act = nn.GELU()

    def forward(self, layer0_feat, layer1_feat):
        # Project layer0
        layer0_proj = self.conv_proj_layer0(layer0_feat)

        # Upsample and project layer1
        layer1_up = F.interpolate(layer1_feat, size=layer0_feat.shape[-2:], mode='bilinear', align_corners=False)
        layer1_proj = self.conv_proj_layer1(layer1_up)

        # Add projections
        fused = layer0_proj + layer1_proj

        # Normalize (BCHW → BHWC → BCHW)
        fused = fused.permute(0, 2, 3, 1)
        fused = self.norm(fused)
        fused = fused.permute(0, 3, 1, 2)

        return self.act(fused)
```

**Module 2: PrototypeExtractor**
```python
class PrototypeExtractor(nn.Module):
    """Extracts prototypes using learnable query embeddings"""
    def __init__(self, num_prototypes, feature_dim, num_heads):
        super().__init__()
        self.num_prototypes = num_prototypes

        # Learnable query embeddings
        self.prototype_queries = nn.Parameter(torch.randn(num_prototypes, feature_dim))
        nn.init.trunc_normal_(self.prototype_queries, std=0.02)

        # Cross-attention
        self.cross_attn = nn.MultiheadAttention(feature_dim, num_heads, batch_first=True)

        # Feedforward
        self.ffn = nn.Sequential(
            nn.Linear(feature_dim, feature_dim * 4),
            nn.GELU(),
            nn.Linear(feature_dim * 4, feature_dim),
        )

        self.norm1 = nn.LayerNorm(feature_dim)
        self.norm2 = nn.LayerNorm(feature_dim)

    def forward(self, fused_features):
        # fused_features: [B, C, H, W]
        B, C, H, W = fused_features.shape

        # Flatten spatial
        feat_flat = fused_features.flatten(2).permute(0, 2, 1)  # [B, HW, C]

        # Expand queries
        queries = self.prototype_queries.unsqueeze(0).expand(B, -1, -1)

        # Cross-attention
        attn_out, _ = self.cross_attn(query=queries, key=feat_flat, value=feat_flat)
        queries = self.norm1(queries + attn_out)

        # Feedforward
        ffn_out = self.ffn(queries)
        prototypes = self.norm2(queries + ffn_out)

        return prototypes
```

**Module 3: PrototypeConditioningModule**
```python
class PrototypeConditioningModule(nn.Module):
    """Conditions current features on previous prototypes"""
    def __init__(self, input_dim, output_dim, num_heads):
        super().__init__()
        self.output_dim = output_dim

        # Project input
        self.input_proj = nn.Conv2d(input_dim, output_dim, 1)

        # Cross-attention
        self.cross_attn = nn.MultiheadAttention(output_dim, num_heads, batch_first=True)

        self.norm = nn.LayerNorm(output_dim)

    def forward(self, combined_features, prototypes):
        # combined_features: [B, C_in, H, W]
        # prototypes: [B, num_proto, C] or None

        if prototypes is None:
            # First frame: return zeros
            B, _, H, W = combined_features.shape
            return torch.zeros(B, self.output_dim, H, W,
                             device=combined_features.device,
                             dtype=combined_features.dtype)

        # Project
        feat_proj = self.input_proj(combined_features)
        B, C, H, W = feat_proj.shape

        # Flatten
        feat_flat = feat_proj.flatten(2).permute(0, 2, 1)  # [B, HW, C]

        # Cross-attention
        attn_out, _ = self.cross_attn(query=feat_flat, key=prototypes, value=prototypes)

        # Residual + norm
        feat_enhanced = self.norm(feat_flat + attn_out)

        # Reshape
        feat_enhanced = feat_enhanced.permute(0, 2, 1).view(B, C, H, W)

        return feat_enhanced
```

**Module 4: MaskRefinementHead**
```python
class MaskRefinementHead(nn.Module):
    """Generates refined masks from enhanced features and decoder tokens"""
    def __init__(self, hidden_dim, transformer_dim, num_refine_tokens):
        super().__init__()

        # Project upscaled_embedding to hidden_dim
        # Assuming upscaled_C = transformer_dim // 8
        self.upscaled_to_hidden = nn.Conv2d(transformer_dim // 8, hidden_dim, 1, bias=False)

        # MLP for refine tokens
        self.token_mlp = nn.Sequential(
            nn.Linear(transformer_dim, transformer_dim * 2),
            nn.GELU(),
            nn.Linear(transformer_dim * 2, transformer_dim),
        )

        # Project to hidden_dim for modulation
        self.token_to_hidden = nn.Linear(transformer_dim, hidden_dim)

        # Final conv to generate mask
        self.mask_conv = nn.Sequential(
            nn.Conv2d(hidden_dim, hidden_dim // 2, 3, padding=1),
            nn.LayerNorm([hidden_dim // 2]),  # Will need to permute for this
            nn.GELU(),
            nn.Conv2d(hidden_dim // 2, 1, 1),
        )

        self.norm = nn.LayerNorm(hidden_dim)

    def forward(self, cross_attn_result, upscaled_embedding, refine_tokens_out):
        """
        Args:
            cross_attn_result: [B, hidden_dim, H, W]
            upscaled_embedding: [B, upscaled_C, H_up, W_up]
            refine_tokens_out: [B, N, transformer_dim]
        Returns:
            refine_masks: [B, 1, H_up, W_up]
        """
        B = upscaled_embedding.size(0)
        H_up, W_up = upscaled_embedding.shape[-2:]

        # Project upscaled_embedding to hidden_dim
        upscaled_proj = self.upscaled_to_hidden(upscaled_embedding)  # [B, hidden_dim, H_up, W_up]

        # Resize cross_attn_result to match upscaled size
        cross_attn_resized = F.interpolate(
            cross_attn_result,
            size=(H_up, W_up),
            mode='bilinear',
            align_corners=False
        )  # [B, hidden_dim, H_up, W_up]

        # Add to create enhanced features
        enhanced_feat = upscaled_proj + cross_attn_resized  # [B, hidden_dim, H_up, W_up]

        # Process refine tokens
        refine_tokens_processed = self.token_mlp(refine_tokens_out)  # [B, N, transformer_dim]
        token_feat = refine_tokens_processed.mean(dim=1)  # [B, transformer_dim]
        token_weights = self.token_to_hidden(token_feat)  # [B, hidden_dim]

        # Reshape for broadcasting
        token_weights = token_weights.unsqueeze(-1).unsqueeze(-1)  # [B, hidden_dim, 1, 1]

        # Modulate enhanced features
        modulated_feat = enhanced_feat * (1 + token_weights)  # [B, hidden_dim, H_up, W_up]

        # Normalize (permute for LayerNorm)
        modulated_feat = modulated_feat.permute(0, 2, 3, 1)  # [B, H_up, W_up, hidden_dim]
        modulated_feat = self.norm(modulated_feat)
        modulated_feat = modulated_feat.permute(0, 3, 1, 2)  # [B, hidden_dim, H_up, W_up]

        # Generate refined mask
        # Note: mask_conv has LayerNorm which expects [B, C, H, W]
        # We need to handle this carefully
        x = self.mask_conv[0](modulated_feat)  # Conv: [B, hidden_dim//2, H_up, W_up]
        # LayerNorm expects [B, H, W, C]
        x = x.permute(0, 2, 3, 1)
        x = self.mask_conv[1](x)
        x = x.permute(0, 3, 1, 2)
        x = self.mask_conv[2](x)  # GELU
        refine_masks = self.mask_conv[3](x)  # Final conv: [B, 1, H_up, W_up]

        return refine_masks
```
